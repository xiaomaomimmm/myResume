# 冀晓禹作品集

一个基于 Three.js 的交互式作品集网页。

- 入口页面：`index.html`
- 后台编辑：`settings/`
- 配置文件：`portfolio-config.json`

## 本地预览

不要直接双击 `index.html`。浏览器会拦截本地模块和作品资源，页面会无法显示。

在 Mac 上双击项目里的 `本地预览.command`，它会启动本地服务器并自动打开作品集。

也可以在项目文件夹中运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 天气

`src/weather.js` 是照 Unity 工程 CatPlanet 的 `MeadowWeather` 移植的一版运行时天气，只改观感，不动场景资产：

- **预设参数表**：晴 / 雨 / 雪 / 尘 / 雾，每份是一组数字（雾起止、太阳强度、湿滑度、粒子量、薄雾强度）+ 一组颜色；主题只负责调色板，切年时按 1.9 秒 smoothstep 过渡插值整份参数。
- **粒子**：雨丝、雪花、浮尘各是一个批次，每颗四边形的中心与随机种子烘在顶点属性里，下落 / 循环 / 摆动全在顶点着色器里算，CPU 每帧只更新一次 uniform，一个 draw call。
- **近景薄雾**：一张全屏 quad，颜色跟深度雾同一份，把视线和地面求交后采一张运行时生成的四通道噪声，所以近处是一团一团而不是一层白纱。
- **地表响应**：下雨时地面 / 道路按 `wetness` 压暗变冷、降粗糙度，并在地面铺一层会扩散、会灭的水波环；下雪时按 `snow` 比例混向「按底色亮度定的冷白」，只抬一档明度而不是刷成纯白。
- 天空和雾用「亮度守恒」的去饱和混合，不会把暗色主题洗成灰白。

调试时可以用 URL 参数直接看某一种天气：

```
http://localhost:4173/?weather=rain
```

可选 `clear` / `rain` / `snow` / `sand` / `fog`。代码里也可以用 `weather.setKind('fog')` 或 `weather.cycle()`。
